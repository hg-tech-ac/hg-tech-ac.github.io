# HG TECH AC

## 장치

- `TECH`: 기술실 본 공간
- `TECH_3D`: 안쪽 3D 작업실

## 현재 구현

- 메인 장치 선택 화면
- TECH 기본 제어 화면
- TECH_3D 기본 제어 화면
- 모바일 대응 공통 스타일
- 수동 켜기·끄기 및 주간 자동화 UI 자리
